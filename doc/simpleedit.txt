*simpleedit.txt*  Shared editing primitives for Vim9

SimpleEdit highlights yanked text and exposes Julia-compatible Unicode input.

:SimpleEditHealth       Show feature health.
:SimpleEditClearYank    Remove the active yank highlight.

                                             *simpleedit#UnicodeTab()*
simpleedit#UnicodeTab() returns an expression-mapping expansion for a complete
LaTeX or emoji token before the cursor, or an empty string when it did not
handle the key.  Completion plugins can therefore give it a well-defined
fallback position.

                                             *simpleedit#UnicodeComplete()*
simpleedit#UnicodeComplete({findstart}, {base}) is the same table behind a
'completefunc' / 'omnifunc' interface, for people who want a completion menu
instead of a <Tab> expansion: >
        setlocal completefunc=simpleedit#UnicodeComplete
<
It follows the |complete-functions| protocol.  On the second call it returns at
most 100 entries, each of them the token, a space, and the symbol it expands
to, in byte order.  SimpleEdit sets no mapping and no option for it; nothing in
the Simple suite calls it either, so it is yours to wire up.

OPTIONS                                                  *simpleedit-options*

g:simpleedit_yank_highlight    Enable yank highlighting (default 1).
g:simpleedit_yank_duration     Highlight duration in milliseconds (default
                               220; must be a positive number).
g:simpleedit_unicode_filetypes Filetypes where UnicodeTab() expands tokens
                               (default ['julia']; must be a List).

Invalid option types fall back to the defaults.
